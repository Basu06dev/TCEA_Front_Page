# TCEA Student Cover Page Maker

An independent, free-to-use student utility for generating professional, printable academic cover pages for assignments and laboratory records at Techno College of Engineering Agartala (TCEA).

The application allows students to enter their academic details, select from four cover-page templates, preview their documents, and print or download them as PDF files.

## ✨ Features

- **Four Cover Page Templates:** Choose from four different academic cover-page designs.
- **A4 Portrait Layout:** Properly formatted for standard A4 printing.
- **TCEA College Logo:** Includes the college logo on the cover page.
- **Live Preview:** Automatically updates the document preview as information is entered.
- **Print Support:** Print cover pages directly through the browser.
- **PDF Download:** Save generated cover pages as PDF files.
- **Local Draft Saving:** Automatically saves entered information in the browser's local storage.
- **No Login Required:** Start creating cover pages without registration.
- **Responsive Interface:** Designed for convenient use across different screen sizes.

## 👨‍🏫 Optional Faculty Controls

The application supports up to three faculty members with flexible faculty sections.

- **Faculty 1:** Displayed by default and remains the primary faculty section.
- **Faculty 2:** Hidden by default and revealed using the **Add another faculty** button.
- **Faculty 3:** Can be revealed by clicking the same button again.
- **Separate Faculty Details:** Each faculty member has individual fields for:
  - Name
  - Designation
  - Department
- **Remove Faculty:** Additional faculty sections can be removed from the form.
- **Dynamic Preview:** The document preview automatically reflects the selected faculty members and their entered details.
- **Local Persistence:** Selected faculty count and faculty information are saved in browser local storage.
- **Draft Migration:** Previously saved drafts containing Faculty 2 are migrated and displayed correctly.

Additional faculty sections remain hidden unless requested, keeping the form and generated document clean and simple.

## 🚀 Run Locally

No additional installation or development environment is required.

1. Download or clone the repository.
2. Extract the ZIP file if downloaded.
3. Open the project folder.
4. Locate `index.html`.
5. Open it in Google Chrome, Microsoft Edge, or Mozilla Firefox.
6. Start creating your academic cover page.

## 💾 Data Storage and Privacy

- Student information and drafts are stored locally in the user's browser.
- No account or login is required.
- Draft information is not intended to be stored on a central server.
- Clearing browser data or local storage may remove saved drafts.

It aims to save students time while providing consistent, professional, and print-ready document layouts.
