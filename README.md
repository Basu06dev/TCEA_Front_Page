# TCEA Student Cover Page Maker — V4.3

Independent student utility for generating printable academic cover pages.

## V4.3 changes
- Reference-format template rebuilt from the supplied screenshot structure.
- Real A4 portrait page: 210mm × 297mm.
- Added outer, inner, and subtle academic border lines.
- Standard order: Assignment-I → college → course title/code → logo → Submitted To → Faculty 1 → Faculty 2 → Submitted By → student details → session/date.
- Faculty 2 uses the same full-width vertical structure and typography as Faculty 1.
- Fifth template is the default **Reference Format**.
- Assignment title field remains removed.
- Assignment-I / Assignment-II / Lab Copy / Practical Report submission types are available.
- Browser Print and PDF download remain supported.
- TCEA logo is used as document branding; the website is an independent student utility.
- Developer information remains inside About only.

## Run
Open `index.html` in a modern browser.

## Print
Use A4, scale 100%, and disable browser headers/footers.


## V4.8 update
Reference Format has been completely removed. Templates 01–04 retain the V4.5 designs and styling.
